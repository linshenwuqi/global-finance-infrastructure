## 关于本书

本书从概念入门，逐步进入账户、跨境支付、投资工具与风险管理。书稿以一般读者为对象，不包含个人财务或开户资料。

后续主题暂定为 跨境资金路径与合规边界、证券账户与 ETF、Crypto 与稳定币、保管安全及组合管理。计划章节尚未完成，不作为已发布正文。

当前为初稿，首次整理日期：2026-10-12。第二至四章由前期讨论的成稿修订；第一章按已确认主题重编。维护记录见[更新记录](更新记录.md)。
