## 💡 为什么要把这些知识放在同一本书里？

过去，我们熟悉的财富路径是：工作、工资、储蓄和投资。现在，港卡、美股、AI、Crypto、海外平台不断进入日常讨论，信息很多，却常常彼此断开。

你可能知道某张银行卡，却不清楚它与收款、消费有什么关系；听过某只 ETF，却分不清指数与投资工具；想尝试海外收入，又不知道赚到钱后怎样管理。

这本书把这些问题放到同一张地图上：

> **先看懂账户和市场，再理解资产与风险；一边积累财富，一边提高创造收入的能力。**

你可以用它建立完整认知，也可以在遇到具体问题时，回来查阅相关章节。
