## 💡 项目起源：从一个小问题，走向一张完整的地图

也许，你是从一个很小的问题走到这里的。

想开一张港卡，查着查着，又遇到了 Wise、PayPal 和美股券商。想了解 Bitcoin，才发现交易所、钱包、私钥是三回事。看到有人靠内容、设计或软件获得海外收入，又开始想：自己的技能，有没有可能被更远的客户看见？

**每查明白一个问题，似乎又冒出三个新问题。** 收藏夹里的攻略越来越多，却很难回答：这些东西，应该怎样放进我自己的生活？

我们熟悉的财富路径，往往是上学、工作、领工资，再把结余存起来或拿去投资。当账户、资产和客户可以跨越地域时，需要想清楚的事情也随之增加：钱从哪里来，放在哪里，如何使用，又怎样支持未来的生活。

整理这份指南，就是希望把这些散落的问题接起来。从港卡和美元出发，走进证券市场，理解 Crypto，再回到年轻人最现实的问题：**如果本金还不多，能不能先让自己的能力连接更大的市场？**

写成一本书，是为了让每一章都能接住上一章留下的疑问；放在 GitHub，是为了让它能够持续修订、被分享，也能让读者指出不清楚的地方。之后，这些内容还会逐步整理成方便阅读和转发的 PDF 合集。

希望你读完后，再遇到一个陌生工具或一条热门投资消息时，心里能多几个有用的问题：它解决什么问题？和我有什么关系？我现在需要它吗？

> **让普通人也能看懂：钱怎么赚、钱往哪放、资产怎么选，以及自己还能拥有哪些选择。**
