## 💡 为什么写这本书？

**一个中国青年对未来财富体系的探索。**

从股票、基金开始，我逐渐接触美元、美股、Crypto 和全球互联网收入。信息并不少，却散落在 X、YouTube、知乎和各类教程中：每一块都有人讲，拼到一起时，反而不知道从哪里开始。

如果你还在上大学，或刚工作几年，也许有同样的困惑：AI 正在改变工作，我该学什么？本金不多，先投资，还是先提升收入？工作、生活和财富，能不能有更多选择？

“逐水草而居”“现金为王”“不买房车”“不结婚生子”等说法让我继续追问：怎样保留生活的余地，怎样安排个人成长与资产积累？我想把零散的信息整理成一张地图，让这些讨论回到每个人自己的处境。

AI 让查阅英文资料、拆解复杂概念更容易，也让普通青年能够把问题问得更深。这本书就是边学、边核实、边整理的结果，希望陪你看懂账户、资产与收入怎样连接。它尤其写给**中国大陆的在校大学生与毕业不久的青年**，并将逐步整理为 PDF，方便阅读与分享。

> **提升认知，连接世界，利用 AI，管理财富。多看懂一点世界，也多拥有一点选择未来的能力。**
