# 维护与发布

在 Codex 中提出下一章主题后，按 AGENTS.md 完成研究、写作和发布。此文件不提供后台调度。

## 两种发布方式

1. 本机 Git 凭据可用时，由 Codex 检查内容并调用发布.ps1，或使用常规 git commit / git push。
2. 本机凭据助手不可用时，由 Codex 使用已授权的 GitHub 连接器发布；上传前读取远程当前分支和文件 SHA，防止覆盖其他修改，再通过公开 HTTPS 拉取到本地。

首次运行中，Git 凭据助手因本机执行权限报错，故采用第二种方式。网页登录与 Git 认证是不同通道，不保证网页登录后命令行立即可推送。

## 本机脚本的前提

发布.ps1 只处理列出的书稿路径，拒绝带入已有暂存内容。运行前由维护者检查 git status / diff、相对链接和公开内容。脚本不会生成新章节或联网核对来源，也不会安装软件或改变安全设置。

发布.ps1 需要可用的 Git 身份与远程写入认证；失败时保留本地提交，不声称已发布。不要为解决推送问题关闭安全限制。
